# Petani Cilik

Game edukasi PAUD (layar tidur/lanskap): Justin membantu Nenek berkebun apel.

Alur: loading → intro komik (ruang keluarga, surat Nenek, naik bus) → kebun & percakapan → Level 1–5 → penutup.

1. Menanam biji sambil berhitung
2. Memilih karung pupuk
3. Menyusun teko penyiram (puzzle)
4. Mengenal bagian tanaman
5. Memetik apel merah

Cara main: buka `index.html` lewat server web (misalnya Live Server), lalu tekan **Ayo Main!**
